# Tanot Solutions homepage

Next.js App Router mockup of the Tanot Solutions homepage. It follows the live `/home2/` design direction and the visual audit: one H1, tighter type, aligned logos, separated Featured On, constrained photos, and a theme background on Insights.

## Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run start
npm run lint
```
